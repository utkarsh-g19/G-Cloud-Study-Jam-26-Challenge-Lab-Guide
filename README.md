## What each guide contains

- **Conceptual part:** what the lab is about and the key ideas, explained simply.
- **Practical part:** numbered steps with the exact clicks and commands.
- **Mistakes to avoid:** errors people usually hit, with the fix.
- **Comparison with the official lab:** how the guide maps to the official instructions.

## How to use

1. Start your lab and keep the official lab page open. It's the source of truth.
2. Follow the guide alongside it. Where a guide says to copy a value from your lab page, copy it from there.
3. Replace placeholders in `UPPERCASE` with your own lab's values.

## Notes

- Labs change over time. Each guide states which version of the official page it was checked against, so if your lab page differs, follow your lab page.
- Never share API keys, project IDs or credentials in screenshots or commits.
- These guides are unofficial study aids, not affiliated with Google. Use them to learn the material, not to skip it.
